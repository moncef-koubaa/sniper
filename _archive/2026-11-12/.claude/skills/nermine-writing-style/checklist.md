# Self-review checklist — every draft passes this before it is saved

Tick every line; a failed line is fixed, not ignored. Record in the run log: `checklist: pass` or what was fixed.

## All documents
- [ ] Every fact, number, tool and title is in `profile/me.md`, and none is tagged `[assumed]` (NV-01).
- [ ] No §5c (studied) technique is described as hands-on / pratique / maîtrise (NV-02, NV-L1, EM-12).
- [ ] Project titles are the exact titles of me.md §4 in the document's language (CV-17).
- [ ] Language = language of the offer / company (CL-15, EM-11); French feminine forms (CL-05).
- [ ] Availability wording is the standing one, or the offer's dates (CL-07, EM-07).
- [ ] Spelling and agreement checked; number format matches the language (CV-12).

## CV
- [ ] Built from a LaTeX source of the library; compiles; **exactly one page**, nothing overflowing (CV-01).
- [ ] Section order and headings (CV-02), header (CV-03), summary paragraph tailored (CV-04, CV-05).
- [ ] Bullets: action → tool → object → result (CV-07), ≤ 2 lines (CV-08), impersonal (CV-09), 2–4 bold keywords (CV-10).
- [ ] Every experience/project with a known number shows it (CV-11).
- [ ] Teaching separate or dropped (CV-15); 3–4 projects, most relevant first (CV-16, TL-01).
- [ ] Skills group closest to the target first (CV-18); `changes.md` lists every change vs the base CV.

## Cover letter
- [ ] One page, 250–390 words (CL-01); header + bold subject (CL-02, CL-03).
- [ ] Salutation uses the real name, or `GENERIC SALUTATION` is flagged in the sheet (CL-04).
- [ ] ¶1 request with INSAT, specialty, availability, exact offer (CL-06, CL-07).
- [ ] ¶2 one proof with tool + number + explicit mapping to the offer (CL-08).
- [ ] ¶3 a concrete, verifiable strength of the company, cited from their page (CL-09, NV-L2).
- [ ] Each real gap named once and paired with fast-learning evidence (CL-10).
- [ ] ¶4 one line (CL-11); closing formula (CL-12); no salary/visa talk (NV-L4).

## Email
- [ ] 120–180 words body (EM-01); subject pattern ≤ 90 chars (EM-02).
- [ ] Real-name salutation or flag (EM-03); specific hook (EM-05); one proof (EM-06); clear request (EM-07);
      CV attached line (EM-08); closing + signature (EM-09); plain text (EM-10).
